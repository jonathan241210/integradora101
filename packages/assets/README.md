# `@arca/assets` — recursos institucionales

Paquete **propuesto** para logos, favicons e imágenes institucionales autorizadas. Esta carpeta contiene únicamente este README: no se incorporan binarios hasta contar con autorización y una spec aprobada.

## Registro requerido por recurso

| Campo | Descripción |
|---|---|
| Nombre y variante | Uso, formato, tamaño y versión del recurso |
| Origen | Archivo fuente o entrega institucional verificable |
| Propietario/licencia | Titular, permiso y restricciones de uso |
| Autorización | Persona/área y evidencia de aprobación |
| Contraste | Fondos permitidos y validación de accesibilidad |
| Optimización | Dimensiones, compresión y presupuesto de peso |
| Versión | Historial y sustitución controlada |

`logo2.png` es únicamente un **candidato pendiente de autorización y spec**; su existencia fuera de este paquete no autoriza copiarlo, publicarlo ni distribuirlo desde aquí.

Las apps deben consumir variantes aprobadas y no duplicar ni alterar recursos institucionales sin registro. Crear el package manifest, procesar imágenes o añadir binarios requiere spec, plan, tasks y revisión de licencia.
