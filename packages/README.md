# Paquetes compartidos

Propuesta de paquetes internos con scope `@arca/*`, consumidos por las apps del monorepo. npm workspaces se planean, pero no hay `package.json`, dependencias ni código implementado.

- [@arca/tokens](tokens/README.md): paleta institucional, tipografía y tokens semánticos para web y mobile.
- [@arca/ui](ui/README.md): componentes accesibles y compartidos para SPAs.
- [@arca/api-client](api-client/README.md): tipos, cliente HTTP y contratos para la API central.
- [@arca/config](config/README.md): configuración compartida de tooling cuando se apruebe.

Cada paquete requiere spec, plan, tasks y aprobación de dependencias antes de crear código.
