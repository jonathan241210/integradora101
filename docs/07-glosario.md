# Glosario

| Término en español | Identificador en inglés | Significado en ARCA-NB |
|---|---|---|
| Ejemplar | `Specimen` | Animal individual bajo cuidado o rehabilitación |
| Especie | `Species` | Clasificación de uno o más ejemplares |
| Recinto | `Enclosure` | Espacio físico asociado a ejemplares y contenido público |
| Hábitat | `Habitat` | Entorno natural o educativo representado en catálogo/juego |
| Boleto | `Ticket` | Derecho de acceso vendido al visitante |
| Venta | `Sale` | Operación registrada en taquilla |
| Taquilla | `BoxOffice` | Punto y módulo de venta presencial |
| Corte / arqueo de caja | `CashClosing` | Conciliación de ventas y efectivo de una jornada |
| Expediente clínico | `MedicalRecord` | Historial de atención de un ejemplar |
| Vacuna | `Vaccination` | Aplicación o registro de vacuna |
| Dieta | `Diet` | Plan o registro de alimentación |
| Tratamiento | `Treatment` | Intervención o cuidado clínico prescrito |
| Decomiso | `Seizure` | Ingreso asociado a rescate/decomiso |
| Médico Veterinario | `Veterinarian` | Rol de atención médico-veterinaria |
| Cajero | `Cashier` | Rol de operación de taquilla |
| Alto Directivo | `Executive` | Rol de lectura de métricas y reportes |
| Administrador General | `Admin` | Rol de administración del sistema |
| Visitante | `Visitor` | Persona usuaria de funciones públicas sin cuenta interna |
| Ficha pedagógica | `EducationalSheet` | Contenido interpretativo para una especie o recinto |
| Código QR | `QrCode` | Identificador escaneable que abre contenido relacionado |
| Cierre de caja | `CashClosing` | Registro de cierre/arqueo diario; mismo concepto que arqueo |
| Historial de cambios | `ActivityLog` | Auditoría de eventos relevantes en el sistema |
| Borrador offline | `OfflineDraft` | Captura local pendiente de sincronización/confirmación por API |
| Registro de aceptación | `AcceptanceCriterion` | Criterio verificable, identificado como CA-xx en specs |
| Regla de negocio | `BusinessRule` | Restricción funcional registrada como RN-xx |
| Zoopedia | `Zoopedia` | Experiencia educativa de juego pendiente de decisión tecnológica |

Los nombres anteriores son contratos de dominio propuestos; si una spec requiere otro concepto, registra su definición y usa un identificador coherente en inglés.
